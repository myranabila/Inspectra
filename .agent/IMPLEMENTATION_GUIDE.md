## 🔍 Validation Checklist

### Equipment Tag Validation:
- [ ] Reactor tags must be R + 3 digits (R001, R099, etc.)
- [ ] Pressure Vessel tags must be P + 3 digits
- [ ] Heat Exchanger tags must be H + 3 digits
- [ ] Storage Tank tags must be T + 3 digits
- [ ] Tower tags must be TW + 3 digits
- [ ] Invalid formats are rejected with clear error message

### Dropdown Restrictions:
- [ ] Equipment Type shows exactly 5 options
- [ ] Area shows exactly 5 options
- [ ] Condition shows exactly 2 options (Satisfactory, Observation)
- [ ] Recommendation shows exactly 2 options (Nil, Monitor)

### Auto-Generation:
- [ ] Inspection ID follows format INS-YYYY-NNN
- [ ] Report Number follows format RPT-YYYY-NNN
- [ ] IDs are unique and sequential
- [ ] IDs are read-only (display only, never editable)

### Section Display:
- [ ] Only selected sections appear for inspector
- [ ] If manager unchecks "External", inspector doesn't see it
- [ ] Section completion tracked correctly
- [ ] Progress indicator shows X/4 sections complete

### Photo Requirements:
- [ ] Each section requires minimum 1 photo
- [ ] Cannot mark section complete without photo
- [ ] Photo upload works correctly
- [ ] Multiple photos per section allowed

### Page 1 Summary:
- [ ] Locked until all required sections complete
- [ ] Shows locked message with clear instruction
- [ ] Unlocks automatically when last section completed
- [ ] Overall Finding required
- [ ] Overall Recommendation required
- [ ] Additional Comments optional

### Role Separation:
- [ ] Manager cannot see/edit inspector fields
- [ ] Inspector cannot see/edit manager fields
- [ ] Both can view auto-generated IDs
- [ ] API enforces role checks (backend validation)

## ⚠️ Common Issues & Solutions

**Issue: Migration fails**
- Solution: Check database connection, restore from backup, run again

**Issue: Equipment tag validation not working**
- Solution: Check prefix matching logic, ensure uppercase normalization

**Issue: Page 1 doesn't unlock**
- Solution: Verify completion logic checks all fields (finding, condition, recommendation, photos)

**Issue: Dropdowns empty**
- Solution: Check API endpoints `/equipment-types` and `/areas` are working

**Issue: Photos not uploading**
- Solution: Verify photo upload endpoint still works, check file size limits
